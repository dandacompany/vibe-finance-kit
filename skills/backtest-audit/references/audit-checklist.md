# Backtest audit checklist

- [ ] 데이터 스냅샷 ID와 원문 해시가 있다
- [ ] 신호 시점과 체결 시점이 분리돼 있다
- [ ] 보정 구간과 평가 구간이 시간순으로 분리돼 있다
- [ ] 평가 구간으로 파라미터를 다시 고르지 않았다
- [ ] 전략과 벤치마크의 초기자금·기간·비용·단위가 같다
- [ ] 수수료와 슬리피지가 0이면 근거가 있다
- [ ] 한 사이클 손 검산을 통과했다
- [ ] 미체결·마지막 보유 포지션 처리 규칙이 있다
- [ ] MDD·회전율·자금 묶임·거래 수를 함께 보고한다
- [ ] 결과를 미래 수익 보장으로 표현하지 않는다
